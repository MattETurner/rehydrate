# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
Code of Conduct. The full text is hosted upstream and authoritative:

  https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be kind, assume good faith, and remember that everyone here
is volunteering their time. We welcome contributors of every background
and experience level. Disagreement is fine; personal attacks are not.

## Scope

This Code applies in all project spaces — GitHub issues, pull
requests, discussions, commit messages, the README and docs, and any
other channel the project uses — and when an individual is
representing the project in public.

## Reporting

If you experience or witness behaviour that violates the Code, please
report it privately to the maintainer via GitHub's
[private vulnerability report form][report]. The form is intended for
security issues but routes to the same private inbox and is the most
reliable way to reach the maintainer without a public trail. Mention
that the report is a Code of Conduct matter.

All reports will be reviewed and investigated promptly and fairly.
Reporters' identities will be kept confidential.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the
standards in the Contributor Covenant and may take any action they
deem appropriate, up to and including removing comments, commits,
issues, or pull requests, and banning contributors temporarily or
permanently.

[cc]: https://www.contributor-covenant.org/
[report]: https://github.com/dm807cam/rehydrate/security/advisories/new
