reHydrate

An offline companion for the reMarkable.

Pulls notebooks over USB, renders ink as sharp PDFs, runs handwriting OCR on your machine, and ships drafts to your own CMS — without touching a cloud you didn't choose.

Download Source

Sync over USB

Your tablet talks to reHydrate at 10.11.99.1 over SSH/SFTP — the same endpoint reMarkable's own developer mode exposes. No Connect subscription, no third-party servers, no pull cycles billed to a storage quota.

The only outbound destinations from the running app are the tablet, the HuggingFace model registry on first OCR run, and your own Ghost or WordPress endpoint when you explicitly publish a draft. A privacy integration test bans every general-purpose HTTP client from the sync, device, and library crates and fails the build if one slips back in.

A library, not a folder

Every pull becomes a new version of every changed document, content-addressed by SHA-256. Browse history per document, restore an older state, garbage- collect what you no longer reference. Renames, moves, archives, and folder edits are first-class — they queue locally and ship to the tablet on the next push.

More than one reMarkable? Keep a library per device and switch between them from the toolbar. Each library is locked at the OS level so two app instances can't trample each other's blob store.

Vector ink

Notebook PDFs render straight from the device's stroke data through PDF's native stroking pipeline — every pen, ballpoint, marker, fineliner, calligraphy stroke and highlighter, with the right caps and joins. Sharp at any zoom, no thumbnail-stitched approximations.

On-device OCR

Click Convert to text on a notebook. A vision-language model loads on your machine — Qwen2.5-VL-7B by default — and transcribes handwriting in any major script. The transcript is stored alongside the notebook in the library's manifest and never pushed to the tablet.

First run downloads the model from HuggingFace (a few GB; visible progress indicator) and stays in your local cache afterwards. Subsequent runs are seconds-of-load + seconds-per-page.

Drafts to your CMS

From a transcript, save as plain text or Markdown, or post a draft directly to your Ghost or WordPress site. Credentials live in your OS keychain. The publish layer's HTTP client is pinned to the host you configured — no redirects, no surprises, no third party in the middle.

Privacy invariants

  • All sync traffic goes to 10.11.99.1. Nothing else, ever.
  • Tauri capabilities are scoped to core:default + opener:default. No tauri-plugin-http in the dep graph; the renderer cannot make arbitrary network calls.
  • The WebView CSP only allows 'self'. Inline event handlers and eval are denied.
  • Credentials sit in the OS keychain (Keychain on macOS, libsecret on Linux, Credential Manager on Windows). Never plaintext on disk.
  • Model weights download once on user-explicit action from huggingface.co only and stay in ~/.cache/huggingface.
  • The publish layer's HTTP client is a wrapper that refuses redirects and rejects any request whose host doesn't match the user-configured CMS URL.
  • A privacy integration test grep-asserts these invariants on every build.

What it's not

  • Not a cloud service.
  • Not a Connect-tier replacement.
  • Not signed or notarized today — first launch on macOS needs a right-click → Open, Windows needs a SmartScreen confirm.
  • Not battle-tested on every Linux distro. Daily on Arch + Wayland and Ubuntu 24.04.

For the curious

Rust workspace, Tauri 2, React 18 + Vite 8 for the renderer. The library is a content-addressed blob store + SQLite version log; manifest edits commit under a single transaction so a crash never leaves you in a half-pushed state. The OCR runtime is mistral.rs with Apple Metal kernels via candle. The publish layer is a hand-rolled ureq + rustls agent.

Get it

Pre-built bundles for macOS (Apple Silicon + Intel), Linux (AppImage and .deb), and Windows (MSI) are attached to each release.

From source:

git clone https://github.com/dm807cam/rehydrate
cd rehydrate
./build.sh

First cold build pulls in Metal + candle + mistral.rs and takes 5–10 minutes. Subsequent builds are seconds.
